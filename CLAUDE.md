# CLAUDE.md

## What belongs in this repo

This repository is public. Never commit planning or internal documents:

- development plans, roadmaps, design notes and spikes;
- marketing, market analyses, launch kits, outreach and email drafts;
- API exploration notes, feature maps and probe output.

Keep them outside the repo (Claude Docs, or a scratch folder). The repo holds the
code, its tests, and documentation for users (`README.md`, `README.zh-CN.md`,
`CHANGELOG.md`, `CONTRIBUTING.md`, `docs/`). Before a commit, check `git status`
for new files that are notes or drafts rather than code, tests or user docs.
